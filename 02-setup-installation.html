Inside settings.py

The most important file in the project — all configuration lives here.

SECRET_KEY

Unique key for your project — never share it with anyone.

DEBUG

Set to True during development. Shows detailed error pages.

INSTALLED_APPS

List where every app you create must be registered.

MIDDLEWARE

Processes incoming HTTP requests and outgoing responses.

DATABASES

SQLite 3 by default — swap the engine for PostgreSQL, SQLAlchemy, MongoDB (NoSQL)… Django is flexible.

STATIC_URL

Location config for static assets — images, CSS, embedded JavaScript.

Quick check

Three questions — click an answer.

1. Why create a virtual environment for each Django project?

Best practice: each project gets its own isolated dependencies via pipenv shell, avoiding conflicts with globally installed packages.

2. What does python -m pip install django do?

-m tells Python to run a module as the main program — here, pip — grabbing the specific Django version you define.

3. python manage.py runserver serves your app at…

The development server runs on 127.0.0.1 (your local machine) on port 8000, showing the Django welcome page.
