Quick check

  
Four questions — click an answer.

  

    

      
1. You created a new app but forgot one required step before the server picks it up. What is it?

      

        
        
        
      

      
Every app must be registered in INSTALLED_APPS — either 'asiatoursagency' or the proper way 'asiatoursagency.apps.AsiatoursagencyConfig'.

    

    

      
2. Why does the app need its own urls.py?

      

        
        
        
      

      
You create it manually per app. The project dispatcher delegates: path('', include('asiatoursagency.urls')) — so more apps = more urls.py files, kept isolated.

    

    

      
3. In path('', views.index), what does the empty string mean?

      

        
        
        
      

      
path() takes two main arguments — route and view. An empty route '' is the root/homepage of the application.

    

    

      
4. If no HTTP method is specified, what kind of request is request by default?

      

        
        
        
      

      
GET, POST, PUT, DELETE are the 4 most common methods; unspecified requests are GETs — used to fetch data and render it on the page.
